

# Job Hunt – MERN Job Portal Application

A full-stack **MERN job portal application** that enables users to browse and search job listings through a responsive web interface. This project demonstrates end-to-end development using MongoDB, Express, React, and Node.js.

---

## ✨ Features

* Browse and search job listings
* Responsive user interface built with React
* RESTful APIs for job data management
* Backend data storage using MongoDB
* Seamless frontend–backend integration

---

## 🛠 Tech Stack 

* **Frontend:** React.js, JavaScript, HTML, CSS, Vite
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Architecture:** MERN Stack, REST APIs

---

## ⚙️ Setup 

```bash
git clone https://github.com/Shreyas-Sherekar/job-hunt.git
cd job-hunt
```

**Backend**

```bash
cd backend
npm install
npm run dev
```

**Frontend**

```bash
cd frontend
npm install
npm run dev
```
